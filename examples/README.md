# 效果示例

这里放的是**真实产出，不是手写的样板**。

## `BV1A9xh6ZEg4-速读稿.md`

- 原视频：[【最新完整版】菲尔兹奖得主邓煜公开演讲：AI、数学、人类应该往哪走？](https://www.bilibili.com/video/BV1A9xh6ZEg4)（25 分 04 秒）
- 怎么产生的：

```bash
node bilisum.mjs get "https://b23.tv/wexc2No"
# → cache/BV1A9xh6ZEg4.transcript.md（中间产物：19556 字 + 视频基本信息 + 热门评论）
# → 对话里的模型读这份转写，写成上面那份速读稿
```

- 耗时：该视频无官方字幕，走本地 SenseVoice 识别，约 3–5 分钟（视 CPU）。
- 这份稿子里除了一节面向作者本人的私人段落被删掉之外，**一个字没改**。
